# [TE - Tiny Editor](https://git2358.github.io/TE/)

TE is a simple, easy to use Tiny HTML, CSS, JS Editor with built in [Tachyons CSS](https://github.com/tachyons-css/tachyons) for quick website mockups!

View this TE webapp here: [TE - Tiny Editor](https://git2358.github.io/TE/)

***

### How to use

> menu tags

`[S]` = copy **share** link

`[D]` = to **download** a .zip of your project

`[T]` = position editors to **top**

`[R]` = position editors to **right**

`[B]` = position editors to **bottom**

`[L]` = position editors to **left**

`[V]` = jump to **viewer** (works best in top/bottom view layout)

`[X]` = reset editors focus

`[P]` = name your **project**
